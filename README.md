# 搞死诈骗犯 網站複刻（靜態版）

復刻自 https://sjfzlm.com/ 的「搞死诈骗犯 Anti-Scam League」示範網站。
純靜態 HTML / CSS / JS，無需構建步驟，使用資料夾式乾淨網址（/about、/news、/news/1 …）。

## 頁面結構
- `/` 首頁（Hero / 我們的服務 / 活動公告 / 最新動態 / 合作夥伴 / 免費諮詢）
- `/about/` 關於我們（核心價值、發展歷程）
- `/news/` 最新動態列表（含分類篩選）
- `/news/1/` ~ `/news/6/` 新聞詳情
- `/404.html` 頁面未找到

## 本地預覽
因使用絕對路徑 `/assets/...`，請以本地伺服器開啟（不要直接雙擊 html）：

```bash
# 在專案根目錄執行任一：
python -m http.server 8080
# 或
npx serve .
```

然後瀏覽 http://localhost:8080/

## 說明
原站為 AI 生成的 Hostinger Horizons / Vite 模板，抓取到的 `/news` 與 `/news/1` 等路由內容不一致（首頁為反詐主題、子頁回傳了法務佔位內容與 404）。
本複刻以最連貫的「反詐主題」為基準，重寫為自洽、可運行的多頁靜態站，新聞詳情正文為合理補齊內容。
